# Painel do Escritório (versão preliminar)

Um painel único para organizar as quatro frentes do escritório **num só lugar e ligadas entre si**:

| Módulo | O que faz |
|---|---|
| 🏠 **Início** | Visão do dia: saldo do mês, contas a receber/pagar, projetos com prazo próximo, próximos posts e alertas automáticos. |
| 📋 **Projetos** | Quadro Kanban (A fazer → Em andamento → Revisão → Concluído), com cliente, prazo, valor e progresso. Arraste os cartões entre colunas. |
| 💰 **Financeiro** | Entradas e saídas, categorias, pago/pendente, gráfico dos últimos 6 meses, exportação para Excel (CSV). |
| 📸 **Instagram** | Calendário editorial: post por dia, formato (Feed, Carrossel, Reels, Stories), estado (Ideia → Produção → Agendado → Publicado), legenda e hashtags com botão de copiar. |
| 🎞️ **Mídia** | Biblioteca de ficheiros (links do Drive/Canva/Dropbox ou imagens pequenas), com tags e pesquisa. |

## A integração

Tudo gira à volta do **projeto/cliente**:

- cada lançamento financeiro pode ser ligado a um projeto → o cartão mostra *recebido / valor total*;
- cada post do Instagram pode ser ligado a um projeto e ter mídia anexada da biblioteca;
- o Início cruza tudo e avisa: prazos a vencer, recebimentos atrasados, contas a pagar e posts próximos ainda sem mídia.

## Como usar

Abra o link do GitHub Pages — não precisa instalar nada. Vem com **dados de exemplo**; para começar do zero vá a *Configurações → Apagar dados de exemplo*.

> ⚠️ Nesta versão preliminar os dados ficam guardados **no navegador** de quem usa. Faça *Configurações → Exportar backup* com regularidade. Numa próxima versão: login, dados na nuvem partilhados pela equipa e ligação direta ao Instagram/banco.
